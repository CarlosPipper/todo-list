# To-Do List

Aplicação web simples para gerenciamento de tarefas.

## Funcionalidades

* Adicionar tarefas
* Marcar tarefas como concluídas
* Excluir tarefas
* Interface simples e responsiva

## Tecnologias

* HTML5
* CSS3
* JavaScript

## Conceitos praticados

* Manipulação do DOM
* Funções
* Eventos
* Condicionais
* Criação e remoção de elementos
* Classes CSS com JavaScript
